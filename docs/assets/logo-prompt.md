## Web research (what “good” means in 2025–2026)

Sources informing the jury:

- SaaS marks need a **symbol + wordmark system**; the symbol must survive favicon / app-tile sizes ([Logotouse SaaS patterns](https://www.logotouse.com/post/saas-logo-design-patterns-that-convert-and-scale), [tech logo trends 2026](https://www.logotouse.com/post/tech-company-logo-trends))
- **Shape-first / silhouette test**: if it fails as pure black at ~40px, it is too complex
- AI category is flooded with brains, nodes, hexagons, sparkles, soft orbs, swirls — strong brands **design around** those clichés ([Avocado](https://theavocado.co/articles/branding-ai-startups-deep-tech/), [D1S1](https://d1s1.com/blog/ai-brands-designing-around-the-cliche), [Ebaq](https://www.ebaqdesign.com/blog/ai-startups-logos))
- Brand from **unique product behaviour**, not “visualize intelligence”
- Bridge/gateway metaphors work when they signal **trust + controlled passage**, not literal civil-engineering scenes ([Monibridge letter-as-bridge](https://clarylifeglobal.com/monibridge-brand-identity/), Bridgenext case patterns)
- NN/g: keep icons schematic; pair with text labels in UI (wordmark “AI Workspace” stays outside the mark)

### Why E wins

Unique sentence competitors cannot honestly steal:

> Remote users pass a **controlled gate** (Bridge / invite-only) to reach **private local intelligence** that never leaves home.

Mapping:

| Form | Meaning |
|------|---------|
| Thick left pillar | Local Worker / GPU weight |
| Slimmer right pillar | Remote clients arriving |
| Lintel | Bridge path |
| Teal rounded-square ember in the void | Local model / private core |
| Empty doorway | Permissioned passage (not public LM Studio) |

## Winning production prompt

```text
FINAL WINNING MARK — after research-backed rejection of AI clichés (no brain, nodes, hexagon, sparkle, swirl, planet-orbit, glowing orb) and after rejecting overly literal bridge dioramas that fail the 32px silhouette test.

PRODUCT TRUTH ONLY COMPETITORS CANNOT HONESTLY CLAIM:
Remote users pass through a controlled GATE (Bridge, invite-only) to reach PRIVATE local intelligence (GPU/LM Studio that never leaves home).

CONCEPT NAME: “Permission Gateway + Local Ember”

GEOMETRY (must be this exact structure — bold, chunky, icon-first):
- One sculpted GATEWAY: two thick vertical pillars + one short thick lintel on top, forming a clear Π / doorway silhouette. Pillars and lintel are continuous dark brushed graphite metal with soft copper edge only on the lintel underside.
- LEFT pillar slightly thicker/heavier (local home weight). RIGHT pillar slightly slimmer (remote arrival). Subtle asymmetry = memorability.
- INSIDE the doorway void: a single small floating ROUNDED-SQUARE ember of translucent teal glass (the local model core). Not a sphere planet. Not a crystal shard forest. One gem only, centered in the opening, soft restrained inner light.
- Tiny hairline copper pin from lintel down to the ember (Bridge handshake) — optional micro-detail; if it hurts clarity at small size, omit.

CRAFT RULES FROM 2026 SaaS LOGO RESEARCH:
- Shape-first: recognizable as pure black silhouette.
- One focal point (the teal ember in the gate).
- Thick forms, no filigree, no heatsinks, no tablets, no books, no text/letters/wordmark/watermark.
- Square 1:1, transparent background, generous padding, slight 3/4 hero angle.
- Materials: Octane/Redshift premium metal + glass; calm enterprise prestige matching dark UI (graphite + copper + teal). No purple. No neon overload. No cartoon.

Mood: sovereign, invite-only, remote-capable, trustworthy workspace doorway — not “generic AI.”
```
